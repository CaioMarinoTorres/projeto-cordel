## 💡 Sobre

Uma página inspirada em cordel, desenvolvida a partir do curso de HTML5 e CSS3 do **Curso em Vídeo**.

Utilizada como prática para:

* HTML básico
* CSS
* Efeito **parallax**
* Uso de imagens como background

Sem muita complexidade — a ideia aqui é só mostrar domínio do básico.
